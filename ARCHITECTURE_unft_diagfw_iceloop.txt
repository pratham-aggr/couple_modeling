 Unless a message explicitly says otherwise, "the model" / "our run" refers
 to THIS configuration: unfinetuned pz220f0b flux U-Net + interactive

 running (job 7244332 at time of writing). No other checkpoint (sensreg),
 no debias correction, no wind-generator/autoregressive-wind variant is

  Two independently-trained CNNs replace CESM's atmosphere (CAM) entirely.
  No CPL7 coupler is used: POP2 <-> Python server exchange NetCDF files

  Coupling cadence: every 6 simulated hours (4 steps/day).
  ML-CICE cadence:  every simulated month (autoregressive, ramped).

    checkpoint: output/output_cice_solin/best_model.pt
    n_in=6  n_out=6   base=64   SAME UNet class as the flux net, on the
    SAME gx1v7 grid (384,320) -- fully autoregressive, MONTHLY cadence
    (stepped once per simulated month; the coupling loop above runs at

      input (6,384,320):
        SST(t) [live POP SST]             ┐
        SOLIN(t)                          │  6-channel stack
        aice_prev, hi_prev,               │  (own previous month's
        uvel_prev, vvel_prev              ┘   APPLIED state, autoregressive)
           │
           ▼  [same 5-level UNet, base=64, encoder/decoder/skips as above]
      output (6,384,320): aice, hi, uvel, vvel, strocnx, strocny
           │
           ▼  RESIDUAL heads: aice = aice_prev + Δaice (clip 0..1)
                              hi   = hi_prev   + Δhi   (clip >=0)
              uvel,vvel,strocnx,strocny predicted ABSOLUTE

      MID-MONTH SCHEDULING + GLIDE (prevents 1-step aice/hi jumps):
        at mid-month(m): predict mean(m+1) from mean(m) state
        applied field glides LINEARLY from mid-month(m) -> mid-month(m+1)
        melt-heat sink recomputed EVERY 6h step from the *applied*
        (glided) hi change:  melth = rho_ice * L_fusion * d(hi_applied)/dt
                              (capped +-200 W/m2, folded into SHFLX)

  ─────────────── (e) ICE<->OCEAN FLUX COUPLING (cice_coupler.apply) ─────

    f  = clip(aice_applied, 0, 1)
    virt (--ice_virtual, skin-ice floor): f = max(f, 1 - clip((SST+1.8)/0.3,0,1))
         (treats near-freezing water as ice-covered even if the monthly-
          anchored emulator lags -- prevents a runaway polynya/frazil
          feedback between monthly ML-CICE updates)
    ow = 1 - f                                          (open-water frac)

      taux_o  = ow*taux        + f*strocnx    (ice->ocean stress blend)
      tauy_o  = ow*tauy        + f*strocny
      shflx_o = ow*shflx       + melth         (melt heat folded in)
      lhflx_o = ow*lhflx                       (evap masked under ice)
      qflx_o  = ow*qflx
      fsds_o  = ow*fsds                        (SW zeroed under full ice)
      flds_o  = ow*flds + f*(sigma*SST_K^4)    (blackbody blend, NOT
                zero -- avoids ~-300 W/m2 unopposed LWUP under high aice)
      prect_o = prect                          (unweighted, v1 scope)
      IFRAC_out = f              -> written to POP for SST/SSS restoring

    ALL fields above are +INTO-OCEAN, coupler-convention (verified against
    write_cam_gx1v7()'s own contract: shflx/lhflx POSITIVE=INTO OCEAN).

  ───────────────────────── (f) WRITE + LOOP ─────────────────────────────

    write_cam_gx1v7(memo_cam_out.nc, taux_o..prect_o, icefrac=IFRAC_out)
    signal POP (done.flag) -> POP advances one 6h coupling step -> writes
    new memo_sst_in.nc -> back to (a).  No CPL7, no atmosphere model, no

================================================================================
 SUMMARY OF WHAT MAKES THIS "unft + interactive ice" CONFIG DISTINCT
================================================================================
  * TWO neural nets total (flux U-Net + ML-CICE), zero classical bulk-flux
    or atmosphere-model code in the loop.
  * Flux U-Net winds are DIAGNOSED, not autoregressive (5 of 13 output
    channels are logged for analysis only, never fed back) -- this is
    what "pz220f0b / diag_flux_wind" means architecturally.
  * Flux U-Net checkpoint is the UNFINETUNED base weights (no dQ/dSST
    sensreg correction, no regional qnet_debias correction).
  * ML-CICE is fully autoregressive and interactive (closes the ice-SST
    feedback loop; --ice_input_from_emu also closes it on the flux-net's
    OWN ice input channel).
  * Safety clamps --dsst_cap/--tau_cap are OFF in this run.
  * Grid: native gx1v7 (384x320) end-to-end, no CAM-grid detour.
  * Coupling: file-based (memo_sst_in.nc / memo_cam_out.nc), 6h cadence;
    ML-CICE internally steps monthly with a mid-month-to-mid-month glide.
